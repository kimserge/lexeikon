# LexEikôn

Словари древних языков издательства Eikon: Lexidion Syriacum, словарь древнегрузинского (Серебряков), Dillmann — Chrestomathia: glossarium, Тананушко (La-Ru), Bedrossian (Hy-En). Поиск латиницей по согласным, работает без интернета (PWA).

Установка: открыть сайт в Safari (iPhone) → «Поделиться» → «На экран „Домой“»; в Chrome (Android) → «Установить приложение».
