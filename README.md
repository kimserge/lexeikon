# LexEikôn

Словари древних языков издательства Eikon: Lexidion Syriacum, словарь древнегрузинского (Серебряков), Dillmann — Lexicon Linguae Aethiopicae (TraCES, Hamburg; CC BY-NC-SA 4.0) и Chrestomathia: glossarium, Тананушко (La-Ru), Whitaker (La-En), Lebaigue–Quicherat (La-Fr), Bedrossian (Hy-En). Поиск латиницей по согласным, работает без интернета (PWA).

Установка: открыть сайт в Safari (iPhone) → «Поделиться» → «На экран „Домой“»; в Chrome (Android) → «Установить приложение».
